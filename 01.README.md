# Excel VBA Custom Functions

Custom Excel formulas built using VBA and available across all workbooks through PERSONAL.XLSB.

## Functions Included

### OLOOKUP()

A custom lookup function built using VBA that allows you to retrieve values using column headers instead of column index numbers.

Unlike VLOOKUP, there is no need to count columns manually.

#### Syntax

```excel
=OLOOKUP(LookupValue, TableRange, HeaderName)
```

#### Example

```excel
=OLOOKUP("INV1002",A1:E100,"NetSales")
```

Or dynamically using a cell reference:

```excel
=OLOOKUP("INV1002",A1:E100,H1)
```

Where H1 contains:

```text
NetSales
```

#### Benefits

✅ No need to count column index numbers

✅ More readable formulas

✅ Dynamic header selection

✅ Easier to maintain large datasets

✅ Similar to modern lookup functions

#### Example Dataset

| InvoiceID | Customer | City   | Product | NetSales |
| --------- | -------- | ------ | ------- | -------- |
| INV1001   | Reliance | Mumbai | Laptop  | 105000   |
| INV1002   | Tata     | Pune   | Printer | 35000    |

Formula:

```excel
=OLOOKUP("INV1002",A1:E100,"City")
```

Result:

```text
Pune
```

### SUMCOLOR()

Assigns values based on cell colors and calculates a total score.

| Color        | Value |
| ------------ | ----- |
| Light Blue   | 15    |
| Light Green  | 10    |
| Yellow       | 5     |
| Red          | 0     |
| Black        | -5    |
| Other Colors | 0     |

#### Example

```excel
=SUMCOLOR(A1:A100)
```

---

### COUNTIFCOLOR()

Counts the number of cells matching a selected color.

#### Example

```excel
=COUNTIFCOLOR(A1:A100,D1)
```

Where D1 contains the reference color.

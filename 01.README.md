# Excel VBA Custom Functions

Custom Excel formulas built using VBA and available across all workbooks through PERSONAL.XLSB.

## Functions Included

### OLOOKUP()

A more intuitive alternative to VLOOKUP that allows you to use actual column letters instead of manually counting column index numbers.

#### Example

```excel
=OLOOKUP(A1,B:Z,"M")
```

Instead of:

```excel
=VLOOKUP(A1,B:Z,12,FALSE)
```

Benefits:

* No need to count column numbers
* Easier to read and maintain
* More resilient when working with large datasets

---

### SUMCOLOR()

Assigns values based on cell colors and calculates a total score.

| Color        | Value |
| ------------ | ----- |
| Light Blue   | 15    |
| Light Green  | 10    |
| Yellow       | 5     |
| Red          | 0     |
| Black        | -5    |
| Other Colors | 0     |

#### Example

```excel
=SUMCOLOR(A1:A100)
```

---

### COUNTIFCOLOR()

Counts the number of cells matching a selected color.

#### Example

```excel
=COUNTIFCOLOR(A1:A100,D1)
```

Where D1 contains the reference color.
